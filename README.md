# SORTED (trysorted.in) - Website Source Code

## Brand Assets
* **Logo:** `logo.png` (Must be transparent, tightly cropped)
* **Primary Gold:** `#f59e0b`
* **Text Highlight:** `#581c87` (Deep Purple)

## Core Files
* `index.html` - The main website code (includes Gemini fluid canvas background)
* `robots.txt` - SEO file allowing Google to crawl the site
* `sitemap.xml` - XML map for Google Search Console
* `.htaccess` - Server config to force secure HTTPS (SSL)

## How to Edit Prices or Links
1. Open `index.html` in Notepad or VS Code.
2. Press Ctrl+F to find the price (e.g., "1,600") or WhatsApp link.
3. Update the text, save, and upload to the host.
